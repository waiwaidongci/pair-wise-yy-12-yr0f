# hxyfront-62011 马术蹄铁修整档案

源提示词编号：6

做一个面向马术俱乐部蹄铁师的修蹄记录前端项目，可以记录马匹编号、步态问题、蹄形评估、蹄铁类型、钉位、修蹄日期、下次复查日期和照片备注。页面需要有马匹列表、复查提醒、左右前后蹄对比记录、异常步态标记和蹄铁更换历史。

## 技术栈

React + Vite + TypeScript

## 离线协作规则

- **场边断网登记**：蹄铁师登记四蹄蹄形、蹄铁、钉位、疼痛评分，记录进入离线队列；回网后按记录号合并。
- **签字锁定**：兽医签字确认疼痛评分后，该次蹄位方案锁定；绕过签字改锁定蹄位按越权拒绝。
- **合并冲突**：两边都改同一蹄位时保留兽医安全值（疼痛评分），另一版转待处理；未处置时不生成复查通知。
- **失效重算**：马匹档案或复查日期变化后，已签意见和复查通知立即失效并重算。
- **失败重试**：合并失败后从最后确认记录按原号重试，换蹄计数次要账本保证不重复计入。
- **旧档案**：缺基准号的旧档案须先补齐才能合并新记录，历史修蹄仍可查询。

演示路径：回网 → 按记录号合并（R-2026-0001 冲突保留兽医安全值；R-2026-0003 因老骥缺基准号失败）→ 马匹档案补齐基准号 → 按原号重试 → 处置冲突后生成复查通知。锁定记录 R-2026-0002 的签字口令为 `VET-LIN-0002`，可用于验证越权拒绝。
